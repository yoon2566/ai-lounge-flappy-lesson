# 로컬 플래피 개편판

실행 주소: http://127.0.0.1:8160/

미리보기 수업: http://127.0.0.1:8160/lesson?room=F1A001

## 실행

이 폴더에서 PowerShell로 `./start.ps1`을 실행합니다. 별도 패키지 설치 없이 Node.js 내장 모듈을 사용합니다. 서버는 이 컴퓨터의 127.0.0.1에만 바인딩합니다.

Windows **사용자 환경 변수 `2_AI_Sherpa(openroter)`**를 읽어 서버 프로세스에만 전달합니다. 키를 HTML, JS, 설정 파일, 요청 기록에 저장하지 않습니다. 서버를 직접 `node server.mjs`로 실행해도 해당 사용자 변수를 읽습니다.

홈을 처음 열면 **선생님 비밀번호를 직접 정합니다.** 이 비밀번호는 OpenRouter 키와 별개이며 솔트와 해시만 `.local/auth.json`에 저장합니다. 선생님 로그인 후 수업을 만들면 6자리 코드를 받습니다. 학생은 코드로 입장합니다. 선생님은 개별 페이지 열기/잠그기, 전체 잠금/열기, 클래스 삭제를 할 수 있습니다.

## 반영한 개편

1. 공룡 2버전의 `classroom-server.cjs`, 수업 목록·코드 입장 포털을 가져와 로컬 클래스 저장과 페이지 제어에 연결했습니다. 세션 쿠키는 기존 공룡과 충돌하지 않도록 `flappy_teacher`로 구분합니다.
2. 이미지 모델은 **`black-forest-labs/flux-3-image-klein`**, 해상도는 **1K**입니다. 캐릭터 첫 그림은 `캐릭터 설명 + 마젠타 단색 배경 + 픽셀아트 + 오른쪽 바라보기`로 생성합니다. 다음 동작은 저장한 첫 그림을 OpenRouter `input_references`에 실제 첨부하여 별도 생성합니다. 한 장에 두 캐릭터를 그리라는 요청은 없습니다. 첫 그림과 다음 동작은 각각 저장하고, 두 번째 그림만 재생성할 수 있습니다.
3. 1·2학년용 공룡 3버전의 하늘색·초록색 화면, 좌측 대화/우측 미리보기, 모바일 채팅/미리보기 탭을 가져왔습니다. 도입 3페이지 뒤에 아래 5개 실습을 연결하여 총 8페이지입니다.

## 수업 순서

화면 위의 중복 단계 메뉴는 제거했습니다. 수업 이동은 아래 이전·다음 버튼으로 합니다. 돌기둥 체험에는 `최고 기록 같이 보기`를 복원했고, 두 체험 게임에는 `크게 보기 / 작게 보기`가 있습니다. 확대 시 같은 게임 프레임을 유지하며 Esc로 돌아올 수 있습니다.

2026-11-02 사용자 요청으로 돌기둥 최고 기록을 이전 버전의 서버(`https://ai-lounge-flappy-lesson-20261025.yoon2566.workers.dev`)와 연결했습니다. `.local/connections.json`의 `rankingOrigin`이 이 주소이면 별명 확인·플레이 시작·점수 진행·종료 저장·순위 조회가 모두 기존 서버로 전달됩니다. 기존 서버는 전체 공용 순위이므로 로컬 클래스별 순위가 아닙니다. 클래스·교사 비밀번호·이미지 생성은 로컬 구성을 유지합니다. 기존 서버에는 클래스 API가 없습니다.

공유 모드에서는 기록을 `.local/rankings.json`으로 자동 우회 저장하지 않습니다. 연결 실패를 화면에 알립니다. 예전 로컬 전용 참가 정보와 공유 서버 참가 정보는 브라우저 저장 키를 구분하므로 처음에는 별명을 다시 입력합니다. 기존 사이트와 로컬의 브라우저 저장소도 다르기 때문에 참가자 로그인 상태까지 자동 복사되지는 않습니다. 로컬 OpenRouter 키·교사 쿠키·클래스 코드는 순위 서버로 보내지 않습니다.

연결 설정이 없는 별도 QA 저장소에서는 기존 클래스별 로컬 순위를 사용합니다. `verify-rank-store.mjs`, `verify-game-controls.cjs`, `verify-rank-join.cjs`에서 로컬 저장·클래스 분리·브라우저 공유·가입·확대를 확인했습니다. 공유 연결은 `verify-rank-bridge.mjs`에서 쓰기 요청 전달 규약을 모의 응답으로 확인하고, `verify-rank-shared-live.cjs`에서 실제 서버/로컬 순위 일치와 브라우저 표시를 조회만으로 확인합니다. 운영 순위에 검증용 기록은 추가하지 않았습니다.

1. 돌기둥이 나오는 원본 게임을 직접 해 봅니다. (`4 / 8`)
2. 준비된 쉬운 요청문을 읽거나 고쳐서 실제 AI로 돌기둥 게임 코드를 만듭니다. 코드를 펼쳐 보고 실행하거나 HTML로 받을 수 있습니다. (`5 / 8`)
3. 돌기둥 대신 검은 구름을 피하고 코인을 모으는 변형본을 해 봅니다. (`6 / 8`)
4. 앞 단계에서 학생이 만든 코드를 함께 보내 AI에게 코인 게임으로 바꾸게 합니다. (`7 / 8`)
5. 그 변형 코드를 이어 받아 AI 그림 생성 → 그림 저장과 주소 확인 → 게임에 적용 → 게임 수정으로 진행합니다. (`8 / 8`)

마지막 실습 안의 선택은 주인공 → 배경 → 장애물 → 아이템 → 속도 → 목숨 → 능력 → 소리 → 내 생각입니다. 다음 동작은 문장을 직접 쓰지 않아도 `움직이게 만들기` 버튼으로 생성합니다.

이미지 주소는 로컬 서버가 실제로 저장한 파일의 주소입니다. 미리보기는 이 주소로 이미지를 불러오고, 다운로드와 작품 저장에는 그림 자체를 포함합니다. 현재는 이 컴퓨터에서만 열리는 주소이며 인터넷 공개 호스팅은 아닙니다. 주소 생성 전에는 게임에 자동 적용하지 않습니다.

이전 5페이지 클래스 자료는 첫 실행 때 `rooms.json.before-course-v2`로 백업하고 8페이지 구성으로 옮깁니다. 기존 클래스·비밀번호·그림·학생 작업은 유지합니다. 이전에 전체 열림이었다면 8페이지 모두 열고, 일부만 열었다면 기존 코인 체험 페이지는 6번, 이미지 실습은 8번으로 연결합니다. 새로 생긴 원본 체험과 코드 페이지는 선생님이 열 수 있습니다.

체험 페이지는 기존 플래피의 돌기둥·별빛 코인 비행 엔진을 사용합니다. 이미지 실습은 앞 단계에서 학생이 AI로 만든 변형 코드를 사용하며, 앞 단계 결과가 없는 기존 프로젝트에는 연습용 엔진임을 표시합니다. 바탕 제거 후 두 그림은 동일한 영역과 배율로 256×256에 정리하고 번갈아 표시합니다. 자동 정렬이 완벽하지 않을 때 두 번째 동작의 좌우·위아래·크기를 직접 조절할 수 있습니다. 생성된 캐릭터 일치나 동작 품질은 모델 결과에 따라 달라집니다.

배경·장애물·아이템도 FLUX로 생성하며, 그림에 하이쿠 문장 변환을 넣지 않습니다. `내 생각`의 자유 게임 코드 수정에는 기존 Haiku 모델을 사용합니다. 기존 그림과 설정은 자리표시자로 분리하여 그림 데이터 전체를 다시 생성시키지 않습니다.

## 저장과 재시도

- 클래스/비밀번호 해시: `.local/rooms.json`, `.local/auth.json`
- 생성 원본: `.local/media/`
- 이미지 요청 설명, 참조 이미지 ID, 비용, 상태: `.local/jobs/`
- 작품 게시판: `.local/board/` (로컬 서버만 사용)
- 학생 작업: 브라우저 IndexedDB, 클래스와 탭별 구분. 같은 탭의 새로고침 후 복원됩니다. 탭을 닫거나 브라우저 자료를 지우기 전에 HTML을 저장하세요.
- 게임 HTML은 사용한 그림을 파일 안에 포함하므로 서버가 없어도 실행됩니다.
- 네트워크 확인을 멈춰도 이미 시작된 원격 생성은 계속될 수 있습니다. 같은 요청 ID로 결과를 확인하면 중복 요청하지 않습니다. 첫 그림이 완성됐으면 다음 동작만 재시도합니다.
- 서버 재시작 중 결과를 받지 못한 요청은 미완료 오류로 남기며 자동으로 재과금하지 않습니다.

## 확인한 내용

### 5개 실습 과정 복원 검증

- 실제 AI가 만든 원본 코드 실행 → 그 원본 코드를 보낸 변형 코드 생성·실행 → 같은 코드의 이미지 실습 연결을 확인했습니다.
- 실제 AI 코드 수정 후 기존 그림 유지, 실행, 앞 단계 코드로 되돌리기를 확인했습니다.
- 캐릭터 두 동작·배경·장애물·아이템의 주소 생성과 파일 응답, 명시적 적용, 새로고침 복원, 그림 포함 HTML의 독립 실행을 확인했습니다. 이 호스팅 흐름 검증에서는 이미지 생성 응답만 기존 그림으로 대체하여 추가 이미지 과금을 피했습니다.
- 5·7·8페이지의 API 접근 제한, 선생님 개별/전체 열기·잠그기, 390px 화면의 실제 내용을 확인했습니다.
- 8160 서버를 업데이트하면서 비밀번호 파일과 클래스의 고유 자료는 해시 비교로 보존을 확인했고, 기존 페이지 열림을 8페이지에 맞게 옮겼습니다.
- 증거: `evidence/course-checks.json`, `course-gates.json`, `course-edit-checks.json`, `local-upgrade-check.json`, `course-*.png`.
- `verify-course.cjs`, `verify-course-edit.cjs`는 저장된 실제 AI 결과를 재사용합니다. 해당 결과 JSON이 없으면 실제 유료 요청을 보냅니다. `verify-course-gates.cjs`는 별도 QA 저장소와 포트 8161에서 실행합니다.

### 초기 개편 검증

2026-11-02, 설치된 Chrome의 별도 테스트 프로필과 별도 로컬 저장소(`.local/qa`, 포트 8161)에서 검증했습니다.

- 선생님 로그인, 클래스 생성, 학생 코드 입장, 학생의 클래스 변경 차단, 페이지 잠금/열기, 삭제, 서버 재시작 후 클래스 유지.
- 실제 FLUX 요청 5회: 첫 캐릭터, 첫 그림을 첨부한 다음 동작, 배경, 장애물, 아이템. 모두 성공, 각 $0.009, 합계 $0.045.
- 같은 요청 ID를 재전송했을 때 기존 결과 반환.
- 배경 제거와 두 프레임 재생, 게임 시작·재시작, 속도·목숨·능력·소리 선택.
- 실제 Haiku 코드 수정 응답, 구문 검사, 수정된 게임 시작.
- HTML 다운로드 후 독립 파일 실행, 로컬 작품 저장·게시판 실행, 새로고침 작업 복원.
- 데스크톱 1440×1000, 휴대폰 390×844, 태블릿 1024×768의 Chrome 화면 크기 검증. 실제 휴대폰 하드웨어 검증은 아닙니다.
- API 키 및 서버/비공개 파일이 정적 경로로 노출되지 않는지 확인.
- 최종 서버에서 대기 요청과 연결 오류를 모의 응답으로 주입해, 기다리기 중지·동일 요청 이어가기 안내·이전 게임 유지 확인. 이 복구 검증에는 추가 유료 호출이 없습니다.

`evidence/checks.json`, `extra-checks.json`, 화면 캡처를 참고하세요. `verify.cjs`와 `verify-extra.cjs`는 실제 유료 API 호출을 포함하므로 필요할 때만 실행합니다.

운영 Worker, 기존 플래피 소스·배포, 공룡 소스는 변경하지 않았습니다. 이 개편판은 `local-app` 안에서만 동작합니다. `bootstrap.mjs`는 초기 복사 이력용으로, 완성된 소스가 있으면 덮어쓰기를 차단합니다. 원본 출처와 초기 해시는 `PROVENANCE.json`에 기록했습니다.
