# 플래피 실제 Chrome 실행 과정

2026-11-04. 실제 Chrome에서 학생 화면을 따라 진행한 101장입니다.
index.html을 열고 그림을 누르면 크게 보입니다. 좌우 화살표 키로 다음 그림을 볼 수 있습니다.

입장 → 원본 게임 체험 → 원본 질문 10개/하이쿠 문장/수정/확정 → 최종 프롬프트 → 실제 원본 코드 생성 → 변형 게임 체험 → 변형 질문 10개/확정 → 실제 변형 코드 생성 → AI 그림 만들기 → 그림 주소 생성 → 게임 적용 → 속도/목숨/능력/소리 → 자유 코드 수정 → 로컬 작품 게시판 저장 → 독립 게임 실행.

모든 질문은 실제 하이쿠 응답을 받았습니다. 캐릭터 첫 그림과 다음 동작, 배경, 장애물, 아이템도 실제 생성했습니다. 사용자 화면을 다른 화면으로 꾸민 이미지는 없습니다. 캡처 당시 스크롤 위치와 작은 미리보기도 그대로 담았습니다.

확인한 한계:
- 낮은 높이의 Chrome 창에서는 수업 안의 게임 미리보기가 작게 보였습니다. 최종 게임은 독립 주소에서도 열어 확인했습니다.
- 변형 코드 단계로 이동할 때 한 번 빈 화면이 떠 해당 수업 페이지를 다시 불러온 뒤 이어갔습니다. 질문이나 생성 결과는 사라지지 않았습니다.
- HTML 파일 받기 버튼은 눌렀지만, 브라우저 다운로드 목록 접근이 정책으로 차단되어 다운로드 완료 여부는 확인하지 못했습니다. 작품 게시판 저장과 해당 게임의 독립 주소 실행은 확인했습니다.
- 운영 배포는 하지 않았습니다. 작품 저장과 이미지 주소는 이 컴퓨터의 로컬 서버입니다.
