# 플래피 수업 UI 개편 · 2026-11-04

개편 전 Git 체크포인트: `e6accdc`.

로컬 주소: http://127.0.0.1:8160/

## 적용 내용

- 참여 화면, 선생님 수업 목록, 8쪽 수업, 두 종류의 코드 만들기, 이미지 편집, 작품 게시판을 같은 회색 UI로 통일했다.
- 흰 바탕, 큰 질문, 그림 선택 카드, 아래쪽 음영이 있는 버튼, 확정 개수를 보여 주는 진행 막대를 적용했다.
- 원본 10개와 변형 10개 질문에 총 60개 SVG 선택 그림을 넣었다. 기존 선택 문구, 접근성 이름, 클릭 동작은 유지한다.
- 그림 선택 → AI 문장 읽기·수정 → 확정 → 다음 질문 순서로 화면을 분리했다. 다른 답 고르기로 돌아갈 수 있다.
- 게임 화면은 원래 320:525 비율을 유지하며, 크게 보기와 다시 시작을 유지한다.
- 이미지 편집에서 9개 단계, 그림 생성·호스팅·적용, 저장, 게시판 기능을 유지한다.
- 글자를 읽기 쉽도록 설명·안내 문구의 회색을 진하게 조정했다.
- 데모에서 코드 단계로 넘어갈 때 새 iframe이 빈 문서에 머무르는 현상을 실제 Chrome에서 재현했다. 이전 데모의 문서 정리와 새 iframe의 로딩이 같은 작업에 겹치지 않도록 새 로딩을 다음 작업으로 옮겼고, 빈 문서의 load 이벤트에서는 활성화 메시지를 보내지 않는다.
- 서버에 SVG MIME 타입을 추가했다.
